# Contributing / 参与改进

Use [Issues](https://github.com/davidnyang/publication-typesetting/issues/new/choose) for a reproducible problem or focused proposal. English and Simplified Chinese are welcome.

- Use original synthetic or clearly licensed public material. Do not upload client files, personal data, credentials, private paths or complete logs.
- State the release, agent host, operating system, actual application version, steps and observed output. Separate proposed methods from executed tests.
- Keep changes focused. Explain affected behavior, requirements, limitations and a reproducible check. Preserve original inputs and failed observations.
- Contributions submitted for inclusion are under this repository's MIT License unless explicitly agreed otherwise. Submit only material you have rights to contribute; do not submit application or font files.
- A proposal, review, merge or star is not customer or printer acceptance. Preserve validation limits until new evidence supports an update.

可使用中文或英文反馈。只提交自编合成或明确获准的公开材料，说明版本、环境、复现步骤与实际输出。拟纳入本仓库的贡献默认按 MIT 提供，提交者须有相应权利；不收客户原件、个人信息、凭据、字库或软件安装包。分别登记方法建议、软件操作和业务终验。
