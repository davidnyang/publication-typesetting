# 原生封面与 Corel 跨版本交付

只在用户授权封面/彩页设计、原生文字转换或CDR交换时读取。以下来自单一刊物在CorelDRAW2020的局部实测及官方接口说明，不表示所有版本、字体、刊物或接收方机器均已通过。内文图数、黑白规则不自动套给彩页；也不因加载此参考而授权新设计、安装字体或外发素材。

## 固定身份与可变设计

先把刊名/标识、英文名、机构、刊号、年份/期次等固定身份，与本期标题、导读、主图分开。身份值及模板样式取自本刊原生文件和指定参考；缺项保持未知，旧期号/条码不可未经核对当新期值。可变内容按用户设计要求调整，不借升级风格改固定身份。

优先复制原生对象到独立副本，比较字体、字号、字符间距、逐字混排、对象变换及几何。单词间空格可能具有不同字号；总期号数字也可能混用字体，不能用对象级单一Font/Size覆盖。原生字号与PDF经缩放后的有效字号分别记录，不能互相直接回填。位图里的文字不能反查出可靠的原字体字段；OCR或视觉近似保持推断。

## 可编辑母稿与转曲交付稿

1. 修改前固定输入、版本、哈希及字体环境，保留原件。实际缺字体或输出缺字时，从正确字体环境下的干净副本重开；不把已被替换的文件继续另存成基线。Font名称回读正确仍须核实际字形。
2. 默认保留可改字母稿；用户要求转曲时另存交付副本，明确曲线可移位、缩放、改色，但不再是可直接改字的文字。不要用整页位图冒充可编辑CDR，也不要覆盖唯一文字母稿。
3. 对页、组、PowerClip及母版中的实际文字递归盘点，转换获准范围内所有文字；记录转换前计数和原文，保存关闭重开后复查剩余文字。检查字体使用元数据、输出字体资源和实际字形；隐藏残留字体样式与真正文字依赖要区分。零文字数不代替内容完整性和视觉核对。
4. 字体嵌入、保护字体正常转轮廓、原生文字转曲是不同状态。不修改字体许可位；PDF提取不到字不自动代表缺字，资源已嵌入也不代表字形正确。

## 降版本与比较

- 分别记录创建应用版本、保存目标版本、接收方实际软件版本。CDR元数据中的ProductName可能仍是创建软件；核SaveAs选项、实际格式版本标记及重开结果，不能只看文件名。目标版本按接收方和版面特性选择，不把某个旧版本定为所有任务的默认答案。
- 本机CorelDRAW2020的SaveAs Version14可产生X4格式样本；这只形成兼容目标，不能据此声称已在X4或全部后续安装上实测。保留外观模式可能限制编辑能力；旧功能降级须核实际输出。接收方版本低于目标时重新另存和验收。
- 分开比两次变化：文字转曲前后、同一曲线稿降版本前后。第二组PDF像素一致不能证明第一组也一致。既要保存前后原生对象/图框数据，也要在相同页面盒、分辨率和渲染器下看整页及重点区域。
- 若所有坐标统一偏移而宽高不变，先回读DrawingOrigin、页面原点/单位和PDF结果，统一坐标参照再比较；不能直接整体移位或仅放宽阈值。非统一差异、图形缺失或画面变化仍须定位，不借“坐标系变化”掩盖真实错位。
- 本机跨文档Shape.CopyToLayer曾失败，激活对应文档后Copy/Paste成功。此为特定调用路径经验，不能当所有版本都失败；复制后重新核逐字格式及相对几何。

## 实际输出而非设置值

- 关闭降采样不等于无损。Corel2020的pdfBitmapCompressionType中JPEG=2、ZIP=3；核实际PDF Filter、像素尺寸与解码像素，不仅核UI/脚本数值。有效dpi由像素和实际放置尺寸计算，高dpi设置不能补造原图细节。
- 保存重开可能没有保留PDF出血等设置。每次导出前应用并回读，导出后核MediaBox/TrimBox/BleedBox、照片边界、颜色、完整文字/轮廓及条码。参数写入失败要记录，不伪称成功。
- CMYK矢量+sRGB图片是混合输出，不自动等于正式全CMYK/PDF-X。正确字体和出血、有效条码数字、编辑采用分别不能代替印厂纸张/ICC、RIP、纸样、纸质条码等级或平台提交验收。
- 制作可编辑母稿、转曲交付源、净尺寸审阅/数字候选及印前候选的关系表，按实际需求分包。转曲CDR附件不自动替换已有印前PDF。字体和素材不因收件人缺失而自动打包外发。
