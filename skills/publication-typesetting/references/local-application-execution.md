# 本机软件执行与能力记录

在明确排版/试排任务中优先使用用户已有且适合目标源格式的软件。技能提供决策和步骤，实际控制依赖当前宿主工具、软件许可、字体与文档权限；技能文件本身不会安装应用，也不自动获得桌面控制。

## 选择与执行

先按客户要求的可编辑格式、现有模板和接收版本选择应用，再核当前设备、实际程序版本、控制通道及已测试动作。读取本机绑定（如存在local-context.md），只发现任务相关的程序和工具，不遍历无关业务目录。旧连接或注册表项不算当前可用。

| 对象 | 优先实际通道 | 要核的结果 |
|---|---|---|
| InDesign原生文档 | 已验收的本机脚本/COM，存在adobe-local-ops时按其InDesign参考 | Document对象明确、故事/字体/链接、INDD保存重开、实际PDF |
| CorelDRAW封面/彩页 | 本机可用COM/VBA/脚本或获准UI通道 | 原生对象/逐字混排、保存格式、重开、PDF；高级输出看corel-interchange |
| 飞腾及旧PS链 | 已获准的本机或指定虚拟机应用通道、实际PDF转换器 | FIT/PS/转换PDF各自存在且内容对应；不能用别的解释器冒充 |
| 图片及矢量辅助 | 已核本机Photoshop/Illustrator等的限定动作 | 原图保持、工作副本尺寸/色彩/裁切及置入结果 |

这里是路线选择，不是这些应用在每台电脑都可用。记录软件标识、版本、目标保存版本、通道、主机、任务文件、原有文档和本轮能做的具体动作。能力状态分成发现程序、连接成功、动作实测、候选输出、接收方验证；不要把它们合成一个“已支持”。

在本次操作已有授权时，依次实际执行：核输入与新输出目录 → 读取/复制指定文档 → 原生排版或修改 → recompose/宿主等效操作与溢文检查 → 保存关闭 → 重开本次副本 → 导出 → 回读原生与PDF/预览。保留调用、版本和输出证据；回答中明确用了哪款软件、哪些动作实际执行。描述拟调用不记为已调用。

只操作明确返回的本任务文档，不能用activeDocument猜对象。保留用户原有文档；捕获并恢复确需改变的交互、单位、导出设置。自身脚本只关闭自身创建/打开的副本。可靠API优先，UI受当前可用工具和权限约束；不为弥补缺失通道安装后台控制器或索取密码。

## 失败与恢复

超时或结果不明时先查本任务文件时间/尺寸、相关宿主状态和对话框，判断是否仍在写入；保留日志。不要盲目重复提交、强杀应用、关闭他人文档或自动降低安全设置。确定原因、无在途写入且重试安全后才在新副本/新输出目录有限重试。

通道缺失时具体说明缺的是启动、输入控制、文件访问还是保存导出，继续素材整理等独立工作。只有确实需要用户完成且自己无可用通道的最小一步才请用户协助，不把整项工作推回用户，也不伪造执行回执。

## 方法演练与应用验收

只有建目录、写配置或模型作答，应用执行状态仍是未执行。需要新动作验证时使用获准合成素材先做有界原生测试；不直接用唯一客户稿试错。装有程序不代表授权可自动调用所有功能，实际支持范围按该设备最新回执。

每轮记录：输入/输出哈希、实际应用和保存版本、开始/完成/失败状态、原文及溢文、链接字体图像、重开/输出一致性、原有文档保持、设置恢复、剩余缺口。跨设备验证必须在对应设备实做；旧环境证据不是新主机验收。

委托记录的host.current_run保存当前轮最小字段，历史回执路径进入run_receipts。status只用not_executed/running/completed/failed/unknown；超时但无法判断是否在写入时记unknown，inflight_write_status保持unknown，不能先改completed。应用动作完成和PDF回读分别记录。原有文档为空时只能证明本次未干扰空集合，不能声称已测保护未保存文档的情形。
