# 修改后整篇复核

用于标题、段距、框几何、图片或随文对象的局部修改。方法来自单刊实际返工，数值由本次刊物和文章决定；不将某篇“减框宽”“补空段”的数值复制为通用模板。

G-R01：修改前另存稳定副本，记录目标、允许变量、锁定参数及关联文字链。固定项通常包括已批准字体、字号、行距、字距和标题规则；框宽/框高、缺角、图片位置是否可调仍查本刊配置。留白问题先分清标题段距、可用框容量、绕排、文本串接和输出测量，不先压字、压行距或加目标行尾。

G-R02：标题依该页型的参照对齐。要求居中时先确认相对于标题框、版心还是跨栏区域；核每行对齐状态、框位置及实际输出。字原点、字框和黑色墨迹中心不是同一测量，不能仅凭标点墨迹偏心再手工偏移。修改同级标题时枚举本篇所有同级标题，逐一检查段前、段后、标题内部行距和与后文关系；续页栏顶可能有不同规则，不机械补同样空行。

G-R03：栏底比较使用本页实际栏界、末行基线与墨迹边界，区分有意参差和容量导致少排一行。先查关联框、缺角/绕排与剩余文字，再调整允许的几何，记录单位、页面坐标/跨页坐标。不能将另一页的固定X阈值拿来分栏；异常测量先核分类，再改版。等底不是所有页型的强制要求。

G-R04：每次修改后从改动处追踪到文章结束，并扫描整篇所有页面。先核全文与阅读顺序，再核行首尾、跨栏/跨页接缝、同级标题、栏底、单字/孤行段尾、图片上方和下方、作者单位、篇末标记及溢文。原有问题、新增问题和已消除问题分开。修好目标却新增单字段尾/漏重/碰撞的候选不晋升；保留失败，必要时从稳定副本重做，撤销操作本身不是恢复证据。

G-R05：随文图形会随重新排文移动；根据本轮目标区分应变位置和应保持的轮廓、尺寸、颜色、纵向基线等属性。对明确对象的合理平移另做检查，其他对象沿用原门槛，不因一项失败放宽整页容差。图形的视觉替代、字符编码和可检索性分别记录，不能伪造字符映射。

G-R06：保存、关闭重开后按既定链实际输出。逐页看最终PDF整页，再放大标题、栏底、图边、段尾；量化检查与视觉检查互补。文字/字体、图像与绘制数据保持和最终输出结构可付印是不同结果。只查截图、局部框或导出成功，均不足以交付整个文章。

最小修订记录：基线与候选标识、允许变更、受影响文字链/页、全文与跨页接缝、所有同级标题、栏底、原有/新增/已消除段尾问题、图片/符号、保存重开、实际输出及未通过项。先有实际证据再填“通过”；本清单是执行规程，不是自动拦截器或零错保证。
