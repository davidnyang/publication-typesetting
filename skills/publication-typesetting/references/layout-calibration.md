# 同文校准与自然续排

G-L01：区分参考PDF输出em、基线、字原点、advance和墨迹边界，以及原软件界面字号、tracking、段距。输出测量不能直接反推出未解码的原生字段。坐标需明确单位、页面盒和原点；不能把bbox当文本框、把标题间距当正文行距或把浮点尾差当两套样式。

G-L02：有复刻目标时冻结连续原文与样本，逐项对比字符顺序、行首尾、段尾、字原点、跨框和跨页位置，定位首次分歧及后续传播。行数一致不等于断行一致；断行一致也不等于字距一致。若任务是原创版式，则按已批准设计规范验收，不凭空寻找历史行尾。

G-L03：排版差异按字体度量、语言规则、标点压缩、排版器、框边界、导出量化分开定位。中文标点可能按位置部分压缩，开闭引号空白侧不同；其他语言的断词、连字、双向文字或垂直文字规则需独立验证，不套用中文设置。Tsume、tracking等只是候选机制，先用短合成句证明作用，再用完整稿复核。候选从冻结副本产生，避免反复执行非幂等补偿；不按段ID/目标行尾写补丁。

G-L04：连续故事按实际阅读顺序串接宽窄栏、图下文本和下一页；独立文章用独立故事。检查跨框前后字符、标题与后文、孤行、脚注/图注关系、篇末标记、作者单位和尾页。只能改变本刊允许的标题区、图高、起页或承接页，超配版须登记；未获准不删文或改变锁定字形尺寸、行距、字面和字距来塞稿。允许设计调整的刊物可以在明确批准后变更配置版本并重验，不能秘密改旧参数。

G-L05：固定逐字坐标/强制行尾可用于诊断复现，不能证明任意换稿能力。新规则总分改善但破坏已通过段时先保留稳定版和失败；如要接受取舍，应明确新的验收约定并重验，不能沿用旧的通过结论。完整文章、未参与调参稿件、整期、其他刊物分别是不同覆盖范围。

修改既有文章时还须执行[修改后整篇复核](revision-review.md)。框容量随稿调整与锁定排字参数分开；局部视觉改善不免除全部关联页的重新检查。

G-L06：新稿的编辑精校与旧稿同文参数校准是两类任务。若本刊已允许局部字距调整，可对明确段落或连续片段做小幅、可回退的tracking候选，记录范围与原值/新值，核全文及后续所有关联页；不插目标行尾、不缩字面凑版。该值是这篇稿的编辑例外，不写成通用默认、段ID规则或原版参数已恢复的证据。若新候选改善段尾却压住标题、挤图或制造另一孤行，则不晋升。

G-L07：配版和每篇字数限制优先取发稿单/编辑规定；从旧期推算容量只记估算。栏目顺序、栏网和样式可固定，文章长度、图片占比和允许留白可浮动。新稿不必复刻旧文每个行尾和图高；仍须尊重明确要求及无漏重/溢文/碰撞等硬门槛。
