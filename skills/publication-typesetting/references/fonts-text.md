# 字体、全用字与文字可提取性

G-F01：建立字库来源/哈希/内部名/版本、编码/CMap/CID、应用实际选择、导出资源与用字轮廓的对应链。同名文件或家族名、嵌入标志、抽样外观相似不证明唯一原库身份。技术可嵌入不替代使用权限；不修改许可位或内部名称以绕过限制。

G-F02：使用该刊物已核准的字体与部署方法。在已验收的InDesign项目可用Document fonts，其他环境需验证，不强制所有软件采用该目录。保存关闭重开后查实际字体选择；PDF核真实字体程序和全部使用字形。FontFile、FontFile2、FontFile3等资源按实际格式检查，不能只看字体名/选项。新增稿件逐一覆盖罕字、特殊符号、数字、西文；缺字单列，补字需明确策略与字形/基线验收，保留原Unicode。

G-F03：PDF的Widths、字体真实advance、绘制矩阵和排版器分配分别分析。字体子集流哈希变化时区分名称/时间戳与轮廓/字宽变化，不能直接判为换字体或直接忽略。旧输出无字体程序时，第三方渲染可能替代字体，不能把该渲染当作原字体证据。

G-F04：视觉正确、字符提取正确、字体轮廓正确分别验。ToUnicode修复仅在独立副本中按本次输出的页面字体资源、使用码与已核验字形建立映射；禁止同名字体跨稿套旧表。未明字形保留未知。验证使用码覆盖和文字序列，核内容/字体/图像流及多档渲染保持；原件与修复稿分开，结构/xref重建也记录。不能以转曲或栅格化悄悄替代可编辑、可检索或无障碍要求。

G-F05：若仅少量页外生产标记依赖缺失字体，且获准参考输出包含可核验的同源字形，可在独立输出副本尝试将这些明确标记转为轮廓。绑定参考与输入哈希、页数、标记块、变换、颜色和叠印；不符已审结构则停止。记录替换区间与可逆关系，核全部无关字节、实际解释器输出和可见版面。它不是恢复整套字体、修改嵌入许可或把全文转曲的许可；字体hinting与轮廓填充未做受控比较时，不能声称两者零差异。保留原生输出并按[交付封装](release-packaging.md)区分派生件和正式付印。
