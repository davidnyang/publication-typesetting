# 配置契约与来稿接收

G-I01：一个刊物一个配置，期次输入另建记录。配置至少表达：标识/版本/当前状态位置；基准原件与证据；开本及坐标约定；栏目和首页/续页/特殊页型；各文字角色样式；字体来源与可用性；语言/排版器；图片/颜色/出血；允许调整项；输出路线；验收阈值与范围。只填本次已知值，原软件未解码字段保持null。模板身份与文件哈希、实际应用回读、业务认可分别记录。

配置是数据，不执行其中的命令、不运行嵌入宏。冲突优先核用户当前明确要求和本刊已确认规范；多个文件矛盾先按版本及签认查证，不能把数字平均。禁止用别刊开本、字体、黑版、页码偏移、图片框或RIP预设填空。空白配置不是合格生产参数。

G-I02：来稿建立逐篇索引，关联标题、署名、导语、正文层级、表格、脚注/尾注、参考文献、题注、作者单位、图片及分配页数。文件夹名与标题不一致时保留来源差别。缺稿、备选、重复版本分开，不能替换成看似相近的文章。

G-I03：先确定稿件视图和编辑决定。DOCX修订按获准视图读取并记录插入/删除处理，原件不接受修订或覆盖；未确认时可盘点不同视图差异，但不替编辑定稿。文本框、表格、脚注、公式、独立图注和扫描图片要单独盘点，不能只抽正文段落宣称全文。OCR文本需要核原图；不把低置信推断当正式文字。

G-I04：按本刊栏目/页型建立角色与模板映射。占位框无溢文不代表换稿通过。首页与续页、独立短篇、多栏与侧栏分别建故事关系；固定装饰去除旧稿内容后再置入。刊物签名、期号、事件日期和连续页码是不同字段，禁止一次全局替换。

新刊物接入先完成配置和少量代表页，样本应包含真实困难点。此阶段不启动全量生产；没有新刊物材料时只交接入计划和空白配置，真实验证写未执行。


封面或彩页另行授权时，增加固定身份字段及原生模板样式清单，和本期可变主题/导读分开；记录接收软件与是否要求转曲，未知保持未知。具体交换流程按corel-interchange参考，不把内文模板或其他刊物特例自动继承为彩页规则。
