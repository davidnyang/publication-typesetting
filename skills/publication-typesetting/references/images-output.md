# 配图与输出路线

G-O01：图片从获准的同文素材或明确指定素材池选取，记录与段落/题注的关系和编辑确认状态。来自同文件夹只是来源线索，不证明人物/活动身份或最终选图。保留原图；裁切、灰度/颜色转换、重采样及置入比例另记。按实际置入尺寸核有效分辨率，不以固定像素数通吃所有开本。图框不合比例时在本刊允许变量内调整或提出明确裁切方案，不拉伸。

G-O02：对象存在、链接正常和框坐标正确不保证可见。图像、图框、裁切路径、内容适配和绕排分别核，移动篇末标志或调整图框后看实际输出局部。固定装饰、离散灰条、连续渐变和栅格图分别比较；颜色端点相同不等于整体相同。

G-O03：先按刊物配置选择直接PDF、PS/RIP或其他获准路线。新刊物不得默认走某一厂商PS链、强制灰度、套用旧测试纸张或禁止一切图像压缩。纸张/出血、颜色空间/ICC/黑版、图片处理、字体、叠印和PDF规格必须与本刊用途和厂方条件对应。预览、数字发布、审阅和付印可有不同输出，保存各自版本与原生源关系。

G-O04：导出异常先分层：原生文档→直接PDF→实际PS→解释器/RIP输出。如PS已有字距量化，两解释器同向差异不能归咎于单一解释器。已有的同尺寸矢量PDF封装PS办法仅作为受控候选：保留可编辑源，核页面盒、置入比例/旋转/原点与PPD，在本次输入验证后才能采用。不是通用必经流程。任何PS最小修改都需定位唯一实际调用、保留定义和无关字节、记录差异并验字位/图边界/像素；不得批量全局删除同名调用。

G-O05：输出设置分画面读到、用户确认、请求但未回读；目标布尔值不是最终状态。真实日志的输入/输出与文件哈希优先于程序“Completed”。无响应先核宿主和已生成文件，不盲重复提交或强杀无关程序；无授权控制通道时准备任务包，请用户完成必要操作。密码、凭据不进脚本或知识。

G-O06：输出颜色会受转换影响；检查真实颜色空间、分量、ICC、渐变/图像与叠印，不凭菜单或屏幕认定保留数值。裁切原点以该文件可信页面盒/裁切标记确认，不假设居中或套另一解释器TrimBox。合并后核页序、文字/矩阵、资源和渲染。转换成功、像素相同、PDF规格检查、厂端RIP/纸样和实际付印是不同证据。

G-O07：双栏中的单栏图、获准跨栏图与意外越栏分别处理。有原刊依据和用户许可的跨栏照片，应同时建立相邻窄栏/图下文字绕排，核完整文字链，不能只放宽图边界。优先同比完整画面；用户要求少裁切时先调允许的图框和文字容量，确需裁切另存工作图。dpi元数据改变会改变部分软件默认置入物理尺寸，并不增加像素或细节；不得照抄旧置入百分比。用目标毫米、像素宽高比、实际输出图像矩阵和有效分辨率核对，图框正确不等于图内照片未变形。
