# Changelog / 更新日志

## 0.1.0-preview — 2026-10-13

First public preview of the CHYSON publication-typesetting workflow.

- Chinese workflow instructions, focused references and blank commission records.
- English and Simplified Chinese public documentation and feedback guidance.
- Python standard-library scaffolding and read-only package verification.
- Self-authored two-page Chinese InDesign demonstration, JSX and preview images.
- MIT licensing, explicit requirements and scoped validation records.

This release packages the existing workflow. It adds no validated application, language or production capability. No telemetry, background service, remote installer or automatic updater is included.
