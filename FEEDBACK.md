# Feedback / 使用反馈

[Open the feedback form](https://github.com/davidnyang/publication-typesetting/issues/new?template=feedback.yml). English and Simplified Chinese are welcome. GitHub Issues are public: use synthetic, public or expressly authorized non-sensitive material. Never upload client manuscripts, personal information, credentials, private paths or complete logs.

Include the skill release, host and model, OS, actual application version and intended save target, task, synthetic inputs, minimal steps, expected and actual result, failure location, and redacted evidence. State whether software was actually operated. Preserve the initial failure and the later revision.

Rate clarity, intake completeness, reproducibility, review help and delivery help from 1 to 5, or mark not run/not applicable. Separately record pass/fail/not run for complete text, missing glyphs or overset text, reading order, native reopen and PDF readback. Record actual working and rework time if measured. An average score cannot offset a technical failure.

Stars show interest or appreciation, not a typesetting quality score. Voluntary feedback is subject to selection bias. Reproducibility, cross-publication performance, exposure and business conversion require their own evidence.

## 中文说明

请使用自编、公开或明确获准的非敏感材料。不要提交客户稿件、个人信息、账号、凭据、私有路径或完整日志。

说明版本、宿主与模型、系统、软件实际版本及保存目标、任务和合成输入、复现步骤、预期／实际结果、失败位置与脱敏证据；明确软件是否真的执行，保留首次失败与修订。

五项主观评分：说明清楚、接稿完整、操作可复现、审校帮助、交付帮助；各 1—5 分或未执行／不适用。完整文字、缺字／溢文、阅读顺序、原生重开、PDF 回读另记通过／失败／未执行，并登记实际操作及返工时间。平均分不能抵消技术失败。

Star 代表收藏或赞许，不是质量评级。自愿评价不能推断行业通过率；曝光和业务转化也需要实际证据。
